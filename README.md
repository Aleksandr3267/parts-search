# Поиск автозапчастей (тестовое задание)

React + Redux Toolkit + Bootstrap, без TypeScript. Двухэтапный поиск по API Favorit-parts.

## Запуск

    npm install
    npm run dev

Тестовый ключ из документации уже подставлен. 

## Как работает

1. Пользователь вводит артикул, уходит запрос `number=...`, в ответе список позиций с брендами.
2. Клик по бренду: запрос `number + brand + analogues=on`, в таблице искомая деталь и её аналоги.
3. Цена: минимальная среди складов, где есть остаток (верхнеуровневое `price` по документации не используется). Остаток: поле `count`.

## Структура

- `src/api.js` — запросы к API и обработка ошибок 
- `src/searchSlice.js` — состояние поиска (Redux Toolkit, `createAsyncThunk`), у каждого блока свой статус: idle / loading / done / error
- `src/App.jsx` — интерфейс: форма, список брендов, таблица, лоадер и сообщения об ошибках

## Прокси

API отдаётся по http, а сайт на Vercel работает по https, и браузер заблокирует такой запрос. Поэтому запросы идут на `/api/...`: локально их проксирует Vite (`vite.config.js`), на Vercel — rewrite в `vercel.json`.
